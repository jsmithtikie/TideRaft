# TideRaft

Transforms remote PostgreSQL databases into Docker containers with Nginx proxy and basic authentication for development teams.

TideRaft is aimed at developers who need a straightforward, dependable solution.

**Highlights**

- Transforms remote PostgreSQL databases into
- Docker containers with Nginx proxy
- and basic authentication for development

## Technology Stack

- python
- Modular architecture
- CI-ready (GitHub Actions)

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/TideRaft.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
